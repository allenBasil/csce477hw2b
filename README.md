# Secure Login Implementation
This project demonstrates a basic login form featuring dual-layer validation (client-side and server-side) to prevent malformed submissions. 

## How to Run
1. Install Node.js on your machine.
2. Initialize the project and install Express: `npm init -y` then `npm install express`.
3. Start the server by running: `node server.js`.
4. Open `index.html` in your web browser and attempt to log in.
